# 仪表监测判定标准

> 本文档记录当前程序已经实现的判定逻辑，作为页面展示、服务端筛选和模拟数据验证的共同依据。它描述的是程序规则，不替代现场电能质量标准、保护定值或计量检定规范。

## 1. 判定通则

- 电能质量风险使用严格比较：刚好等于阈值仍为合格，只有低于下限或高于上限才会产生风险。
- 一台设备可以同时出现多项风险，例如通信状态异常且电压 THD 超限。
- 全量统计中，一台设备在每个命中的风险类别中各计一次；“风险设备数”仅按设备计一次。
- 没有采集值（`null`）不会被判定为功率因数、电压、THD 或不平衡度风险；是否异常由设备状态决定。

## 2. 设备状态判定

| 状态码 | 页面显示 | 是否正常 | 含义 |
| --- | --- | --- | --- |
| `OK` | 正常 | 合格 | 设备在线，且程序未设置状态异常。 |
| `PF_LOW` | 功率因数低 | 不合格 | 当前设备状态被标记为功率因数异常。 |
| `VOLTAGE_BAD` | 电压异常 | 不合格 | 当前设备状态被标记为电压异常。 |
| `FAULT` | 通信故障 | 不合格 | 当前设备通信或采集故障。 |
| `NODATA` | 无数据 | 不合格 | 当前设备未取得有效采集数据。 |
| `WAITING` | 等待采集 | 不合格 | 设备处于等待首次或下一次采集状态。 |
| 其他值 | 状态未知 | 不合格 | 未识别的状态不会被当作正常。 |

非 `OK` 状态会命中“设备状态异常”质量风险，并在异常设备、报警故障与设备告警状态页面中出现。

## 3. 电能质量数值判定

| 检测项目 | 字段 | 单位 | 合格范围 | 不合格条件 | 风险显示 |
| --- | --- | --- | --- | --- | --- |
| 总功率因数 | `powerFactorTotal` | 无 | 大于或等于 0.85 | 小于 0.85 | 功率因数偏低 |
| A/B/C 相电压 | `voltageA`、`voltageB`、`voltageC` | V | 每相 198 至 242（含边界） | 任一相小于 198 或大于 242 | 电压越限 |
| A/B/C 相电压总谐波畸变率 | `voltageThdA`、`voltageThdB`、`voltageThdC` | % | 每相小于或等于 5 | 任一相大于 5 | 电压 THD 超限 |
| A/B/C 相电流总谐波畸变率 | `currentThdA`、`currentThdB`、`currentThdC` | % | 每相小于或等于 8 | 任一相大于 8 | 电流 THD 超限 |
| 电压不平衡度 | `voltageUnbalance` | % | 小于或等于 2 | 大于 2 | 电压不平衡 |
| 电流不平衡度 | `currentUnbalance` | % | 小于或等于 3 | 大于 3 | 电流不平衡 |

### 阈值边界示例

- 功率因数 `0.85` 合格，`0.849` 不合格。
- 电压 `198 V`、`242 V` 合格，`197.99 V`、`242.01 V` 不合格。
- 电压 THD `5%` 合格，`5.01%` 不合格。
- 电流 THD `8%` 合格，`8.01%` 不合格。
- 电压不平衡度 `2%` 合格，`2.01%` 不合格。
- 电流不平衡度 `3%` 合格，`3.01%` 不合格。

## 4. 各页面的使用方式

| 页面/功能 | 判定与展示方式 |
| --- | --- |
| 首页异常设备、报警故障 | 仅显示状态码非 `OK` 的当前设备，最多展示 5 台；“显示更多”进入全部异常设备页。 |
| 异常设备 | 仅显示状态码非 `OK` 的设备，并按通信故障、无数据、电压异常、功率因数低、等待采集的优先级排序。 |
| 设备告警状态 | 反映当前设备状态，不代表独立的历史告警事件；正常设备显示“当前没有报警或故障”。 |
| 实时运行、设备拓扑图 | 显示当前状态和采集读数；拓扑卡片的状态颜色由设备���态码决定。 |
| 电能质量 | 服务端以本表规则筛选“仅看风险设备”，并计算状态异常、功率因数低、THD 超限、不平衡超限的全量统计。 |
| 质量历史 | 按所选设备和时间范围展示历史采集值；历史曲线展示原始数据，不会以当前设备状态反向标记旧记录。 |

## 5. 仅展示、未设置合格阈值的值

以下字段目前用于显示、趋势或统计，程序没有合格/不合格阈值，不应把数值大小解释为程序告警：

- 有功功率、无功功率、视在功率：`activePowerKw`、`reactivePowerKvar`、`apparentPowerKva`
- A/B/C 相电流：`currentA`、`currentB`、`currentC`
- 频率：`frequency`
- 累计正向、反向有功电能：`forwardActiveEnergyKwh`、`reverseActiveEnergyKwh`
- 电压、电流总量及其历史采集时间
